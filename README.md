# 鄞州低空智护静态交互原型

本项目为纯静态 HTML、CSS、JavaScript 原型，所有数据、设备、区域、告警、接口和人物均为虚构或脱敏的 mock 演示数据。它不包含真实登录、后端、数据库、UOM 接口、市级平台、车防系统、设备接入、飞行监测或反制控制。

## 入口

- `/`：原型总入口。
- `/apps/zheliban/`：浙里办用户端。
- `/apps/admin/`：公安 PC 后台。

用户端提交的登记证、飞行计划、活动报名与反馈通过同源浏览器本地存储与后台端联动，刷新后两端保持一致；这只是演示手段，不代表真实数据库或跨设备同步。

## 发布范围

该仓库仅包含可公开评审的静态原型、脱敏 mock 数据、演示素材与 GitHub Pages 工作流；原始需求、设计资料、验收文档及本地证据均不上传。

推送 `main` 分支后，GitHub Actions 会将根入口、`apps/` 与 `shared/` 发布为 Pages 站点。
